# Release Notes

All notable changes to SeasonBox will be documented in this file.

---

## Version 1.1.0 (Build 4) - 14.12.2025

### 🌍 New Features

**Multi-Language Support**
- SeasonBox now speaks your language! Choose from 5 languages in Settings
- Available languages: English, Spanish, French, Italian, and German
- All screens and menus are fully translated
- Language preference syncs across the app instantly

### 🎨 Improvements

**Better User Experience**
- Clearer labels and descriptions throughout the app
- Consistent terminology across all screens
- Improved navigation with localized tab names
